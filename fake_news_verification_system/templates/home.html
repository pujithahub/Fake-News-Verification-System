Fake News Verification System

Check a news headline or article using administrator-verified records and a Machine Learning text classifier.

Get Started Login

How it works

  1. Admin adds news checked against reliable sources.
  2. User pastes a headline or article.
  3. The system checks for a verified-record match.
  4. If no match exists, the ML model provides a prediction.

Important: ML prediction is not proof of truth. “REAL” predictions are shown as Unverified unless an admin record matches.
